# Attribution

Kibby was directly inspired by end-4's illogical-impulse project and by the
practical migration of a CachyOS Hyprland desktop away from a tightly coupled
shell installation. Its visual-shell work, Hyprland integration, and component
implementations provide foundational references for parts of Kibby. Kibby
reworks those ideas around independently installable, user-owned modules and is
not an official illogical-impulse distribution.

Optional components may contain modified GPL-3.0 code derived from end-4's
illogical-impulse project or pctrade's end4-pC fork. Each such component must
declare its own provenance. The complete inherited shell and personal migration
journal are intentionally not included in this repository.

Wispr Flow is third-party software and is not redistributed by Kibby.
